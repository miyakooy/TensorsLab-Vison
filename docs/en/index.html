TensorsLab Vision / AI agent toolkit

Create with APIs.
Deliver with control.

TensorsLab Vision combines executable image and video generation skills with persistent task recovery, content-bound approval, and QA-gated delivery. The examples below show what runs today and which steps still need external production tools.

FOR DEVELOPERS & CREATORS

Use the examples as a starting point, then contribute the source assets, constraints, prompts, parameters, QA checks, and known failures that turn a showcase into a reproducible scenario.

PRODUCT POSITIONING

Generation tools built for agent workflows.

Use tl-image or tl-video for a direct generation. Use miaodashi-workshop for multi-deliverable commercial work that needs planning, approval, QA, and selective retries.

Execute

Call supported TensorsLab image and video APIs from installable skills and return local files plus structured JSON.

Resume

Persist accepted task IDs and resume status, waiting, or downloads without creating a second paid generation.

Review

Bind approval to content and source files, then keep generated work blocked until required QA passes.

WORKFLOW READY

Ecommerce product video

Plan a product showcase or social-ad clip from approved product imagery, then generate one reviewed shot at a time with the existing video client. Controlled spoken dialogue, lip sync, subtitles, and final editing remain external steps.

BEST EFFORT

Product cleanup and comparison

The workflow can record a comparison plan and a prompt-driven image edit. It has no mask API, so exact object removal and split-screen compositing are not claimed as deterministic features.

PLAN READY

Detail-page visual kit

Listing-kit separates hero, structure, material, environment, and package tasks. Prices, specifications, legal claims, and final typography should be added in a deterministic design tool.

REFERENCE

Entertainment portrait effects

Multiple references and general image-to-image prompting can support style exploration. This is not a dedicated faceswap, face-swap, identity-consistency, or deepfake pipeline; consent and per-output review are required.

CAPABILITY LABELS

Trust comes from visible limits.

Implemented

Persistent task IDs, resumable status/wait/download operations, content-bound approvals, dispatch records, and QA-gated delivery states.

Best effort

Prompt-driven retouching, object removal, and face transformation through a general image-to-image endpoint.

External work

Masking, deterministic typography, controlled lip sync, batch execution, publishing, and managed collaboration.
