TensorsLab Vision / AI Agent toolkit

API で生成し、
管理して納品する。

TensorsLab Vision は、実行可能な画像・動画生成 Skill に、タスク再開、内容に結び付いた承認、QA 納品判定を組み合わせます。以下の例では、現在実行できる工程と外部ツールが必要な工程を区別します。

開発者とクリエイターへ

単発生成は tl-image / tl-video、計画、承認、QA、選択的再試行が必要な複数成果物は miaodashi-workshop を使用します。

PRODUCT POSITIONING

Agent ワークフローのための生成ツール。

実 API の実行、タスク ID の永続化、承認と QA の記録を一つのオープンソースツールキットにまとめています。

実行

TensorsLab の画像・動画 API を Skill から呼び出し、ローカルファイルと構造化 JSON を返します。

再開

受理された task ID を保存し、新しい有料生成を作らずに状態確認、待機、ダウンロードを再開します。

レビュー

承認を内容と素材に結び付け、必要な QA が通るまで納品状態をブロックします。

LOCAL COVER REFERENCES

ポスター、シーン、商品メイン画像の方向性。

ご提供いただいた四つのキャンペーンカバーをリポジトリ内に保存し、外部画像ホストに依存しない参照素材にしました。

SHOWCASE

Brief からレビュー可能な納品まで、四つの入口。

公開ビジュアルは miaodashi.com の参考作品です。すべての工程がこのリポジトリで自動化されていることを示すものではありません。

WORKFLOW READY

EC 商品ショート動画

承認済みの商品画像から展示または広告クリップを計画し、既存の動画クライアントでショットごとに生成します。台詞、口パク、字幕、最終編集は外部工程です。

BEST EFFORT

商品整理と比較

比較計画とプロンプト主導の画像編集を記録できます。マスク API はないため、正確な消去や分割画面合成を確定的機能としては扱いません。

PLAN READY

商品詳細ページ素材

listing-kit はメイン、構造、素材、シーン、パッケージを別タスクに分けます。価格、仕様、法務文言、最終タイポグラフィは確定的なデザインツールで追加します。

REFERENCE

人物エフェクト

複数の参考画像と汎用 image-to-image でスタイル探索はできます。ただし専用 faceswap、顔同一性保証、Deepfake のパイプラインではありません。本人の同意と全件確認が必要です。
