이커머스와 엔터테인먼트를 위한 시각 참고 사례입니다. 각 카드에서 이 저장소에서 실행할 수 있는 흐름, 최선 노력 생성, 외부 도구가 필요한 단계를 구분합니다.

SHOWCASE

Brief에서 검토 가능한 납품까지, 네 가지 경로.

공개 시각 자료는 miaodashi.com의 참고 작품입니다. 모든 단계가 이 저장소에서 자동화됐다는 뜻은 아닙니다.

WORKFLOW READY

이커머스 상품 숏폼 영상

승인된 상품 이미지로 쇼케이스 또는 광고 클립을 계획하고 기존 비디오 클라이언트로 장면별 생성합니다. 대사, 립싱크, 자막과 최종 편집은 외부 단계입니다.

BEST EFFORT

상품 정리와 비교

비교 계획과 프롬프트 기반 이미지 편집을 기록할 수 있습니다. 마스크 API가 없으므로 정확한 제거와 분할 화면 합성을 확정 기능으로 주장하지 않습니다.

PLAN READY

상세 페이지 시각 세트

listing-kit은 대표, 구조, 소재, 장면과 포장을 별도 작업으로 나눕니다. 가격, 규격, 법적 문구와 최종 타이포그래피는 결정론적 디자인 도구에서 추가해야 합니다.

REFERENCE

인물 효과

여러 참고 이미지와 범용 image-to-image로 스타일 탐색은 가능합니다. 다만 전용 faceswap, 신원 일관성 또는 Deepfake 파이프라인이 아니며, 당사자 동의와 결과별 검토가 필요합니다.
