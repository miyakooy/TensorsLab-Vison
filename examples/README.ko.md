이 갤러리는 공개된 시각 참고 자료를 재현 가능한 커뮤니티 시나리오로 전환하기 위한 출발점입니다. 완성 이미지와 이 저장소에서 처음부터 끝까지 실행할 수 있는 워크플로를 구분합니다.

## 재현 가능한 시나리오의 요건

- 공개 가능하거나 적절히 익명화된 원본 자산;
- 채널, 언어, 비율과 납품 수량;
- 변경할 수 없는 상품 또는 인물 사실;
- Skill, 모델, 프롬프트, 파라미터, QA 규칙과 실패 사례;
- 구현됨, 최선 노력, 외부 후처리 단계의 명확한 구분.

## 현재 작품 방향

| 방향 | 현재 저장소 지원 | 커뮤니티 기여 기회 |
| --- | --- | --- |
| 이커머스 상품 영상 | 상품 쇼케이스·광고 계획, image-to-video 클립 | 구두 소개, 언박싱, 장점, 광고 장면 레시피 |
| 상품 정리·비교 | 프롬프트 기반 편집과 QA 기록 | 승인 편집 영역, 실패 사례, 비교 체크리스트 |
| 상세 페이지 시각 세트 | 대표, 소재, 구조, 장면 작업 계획 | 플랫폼별 규격과 문구 검토 흐름 |
| 인물 효과 | 범용 image-to-image 스타일 탐색 | 동의·권리 확인 템플릿과 신원 QA |

공개 시각 자료는 [중국어 갤러리](README.md)에 있습니다. 모든 효과가 자동화됐다는 뜻은 아닙니다.

## Face swap 경계

범용 image-to-image로 얼굴 교체를 시도할 수 있으나 전용 `faceswap`, `face-swap`, 마스크, 신원 일관성 또는 Deepfake 파이프라인은 아닙니다. 당사자 동의와 사용 권한이 있는 미디어만 사용하고 모든 결과를 검토해야 합니다.

[작품 및 시나리오 Issue 양식](../.github/ISSUE_TEMPLATE/showcase.yml)으로 제안해 주세요. 시나리오 안에서 새 API 클라이언트를 만들지 말고 기존 클라이언트를 재사용합니다.
