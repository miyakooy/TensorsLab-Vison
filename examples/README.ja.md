このギャラリーは公開済みのビジュアル参考を、再現可能なコミュニティシナリオへ変換するための入口です。完成イメージと、このリポジトリで最後まで実行できるワークフローを区別します。

## 再現可能なシナリオに必要なもの

- 公開可能または適切に匿名化した素材;
- 配信先、言語、比率、納品数;
- 変更してはいけない商品または人物の事実;
- Skill、モデル、プロンプト、パラメータ、QA ルール、失敗例;
- 実装済み、ベストエフォート、外部後工程の明確な区分。

## 現在の作品方向

| 方向 | 現在のリポジトリ対応 | コミュニティで求める貢献 |
| --- | --- | --- |
| EC 商品動画 | 商品展示・広告の計画、image-to-video クリップ | 口播、開封、売りの訴求、広告カットのレシピ |
| 商品整理・比較 | プロンプト編集と QA 記録 | 承認済み編集範囲、失敗例、比較チェックリスト |
| 詳細ページ素材 | メイン、素材、構造、シーンを計画 | プラットフォーム別規格と文言確認フロー |
| 人物エフェクト | 汎用 image-to-image のスタイル探索 | 同意・権利確認済みテンプレートと本人確認 QA |

公開ビジュアルは[中国語ギャラリー](README.md)にあります。すべてのエフェクトが自動化済みという意味ではありません。

## Face swap の境界

汎用 image-to-image で顔の置換を試すことはできますが、専用 `faceswap`、`face-swap`、マスク、本人同一性保証、Deepfake パイプラインではありません。本人の同意と利用権がある素材のみを使い、出力を必ず確認してください。

[作品とシナリオ Issue フォーム](../.github/ISSUE_TEMPLATE/showcase.yml)から提案してください。シナリオ内で新しい API クライアントを作らず、既存クライアントを再利用します。
