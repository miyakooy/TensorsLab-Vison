This gallery turns public visual references into a queue of reproducible community scenarios. It distinguishes an outcome image from an end-to-end workflow that can run in this repository.

## What makes a scenario reproducible?

- source assets that are public or appropriately anonymized;
- target channel, language, aspect ratio, and delivery count;
- immutable product or character facts;
- skill, model, prompt, parameters, QA rules, and failed attempts;
- a clear boundary between implemented work, best-effort generation, and external post-production.

Public reference visuals are shown in the [Chinese gallery](README.md). They do not imply that every effect is already automated.

## Face swap boundary

The repository can attempt face replacement through a general image-to-image endpoint. It is not a dedicated `faceswap`, `face-swap`, masking, identity-consistency, or deepfake pipeline. Use only authorized media with the depicted person's consent, and review every output.

Propose a scenario through the [showcase issue form](../.github/ISSUE_TEMPLATE/showcase.yml). Reuse the existing clients rather than creating another API client inside a scenario pack.
